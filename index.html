Ecosystem Architecture

A look into the structural design of Project High-Desert—engineered for performance, hardware redundancy, and logical isolation.

Compute & Virtualization

A distributed 3-Node Proxmox VE 8.1 HA Cluster running on bare-metal systems, backed up to a dedicated Basin-Vault server running Proxmox Backup Server (PBS).

  • Summit-Core (Anastasia): NVMe Data Core
  • Mesa-01 & Ridge-01: HA Nodes
  • Basin-Vault (Petrovia): PBS Target

Network & Isolation

Engineered for strict logical segmentation. Workloads run inside an isolated laboratory LAN behind stateful firewall rules to protect the wider environment.

  • Router: MikroTik RB5009
  • Backbone: TRENDnet 16-Port Switch
  • Subnet: Isolated LAN (10.x.x.x/24)

DevOps & Application

A custom CI/CD pipeline built on Windows/Linux automation hooks. Runs Nginx-Alpine containerized web environments on top of an optimized Debian 12 LXC.

  • Orchestration: Docker Compose
  • Automation: push.bat & deploy alias
  • Identity: Cloudflare DNS Interface
